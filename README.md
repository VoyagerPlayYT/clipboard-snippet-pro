## 🌟 Описание проекта

**Clipboard & Snippet Manager Pro** — это профессиональный инструмент продуктивности, избавляющий от рутины повторного ввода одних и тех же текстовых данных: банковских реквизитов, адресов доставки, сниппетов кода, ссылок и шаблонов ответов клиентам.

### Ключевые возможности:
- 🕒 **Непрерывный перехват буфера Windows**: утилита автоматически сохраняет в историю все скопированные фрагменты (тексты, ссылки, JSON, код) без потери данных при случайной перезаписи.
- ⚡ **Мгновенный поиск (Live Filtering)**: фильтрация сотен записей по ключевым словам по мере набора текста в поисковой строке.
- ⭐ **Каталог сниппетов и шаблонов**: организация часто используемых текстовых заготовок по категориям («Личное», «Финансы», «Сеть», «Код», «Переписка»).
- 🖱 **Копирование в 1 действие**: двойной клик по любому элементу мгновенно помещает его в буфер обмена с всплывающим уведомлением.
- 🔒 **Полная приватность**: все записи хранятся в зашифрованной локальной базе данных SQLite на вашем диске, исключая сбор телеметрии.

## 🛠 Стек технологий

- **Язык**: Python 3.11+
- **Графический интерфейс**: PyQt6 (стильная кастомная темная тема Cyber Slate, отзывчивый список с QListWidget, модульные диалоги)
- **База данных**: SQLite3 с автоматической миграцией схемы и оптимизированными индексами
- **Интеграция с ОС**: QClipboard Event Loop Listener

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

В изолированном виде менеджер буфера работает только на одном компьютере. В связке с домашним сервером он превращается в мощный распределенный сервис:

1. **Бесшовная синхронизация буфера между всеми устройствами (Cross-Device Clipboard)**:
   - Скопировав текст, ссылку или фото на рабочем ноутбуке, вы можете мгновенно вставить их на домашнем ПК или смартфоне через серверный API.
2. **Безопасная альтернатива облаку Microsoft**:
   - Стандартный облачный буфер Windows отправляет конфиденциальные данные (номера карт, пароли, переписку) на сервера Microsoft. Домашний сервер позволяет развернуть собственный зашифрованный сервер синхронизации без утечек.
3. **Общая семейная база сниппетов**:
   - На сервере формируется общая семейная библиотека: паспортные данные, номера полисов ОМС, СНИЛС, реквизиты ЖКХ и домашний адрес, доступные родителям в 1 клик в любое время.
